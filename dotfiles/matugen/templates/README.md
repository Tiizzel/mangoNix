# Matugen Templates

This directory contains Matugen color templates.

## Structure

- `builtin/` — Templates copied from Noctalia's active built-in templates:
  - `btop` (`btop.theme`)
  - `ghostty` (`ghostty`)
  - `gtk` (`gtk3.css`, `gtk4.css`)
  - `kde` (`kcolorscheme.colors`)
  - `kitty` (`kitty.conf`)
  - `mango` (`mango.conf`)
  - `qt` (`qtct.conf`)

- `community/` — Templates copied from Noctalia's active community templates:
  - `antigravity`, `vscode`
  - `bat`, `fastfetch`, `fuzzel`, `fzf`, `lazygit`, `yazi`
  - `brave`, `zen-browser`, `pywalfox`
  - `claude-code`, `opencode`
  - `discord`, `steam`, `heroiclauncher`, `prismlauncher`
  - `gimp`, `libreoffice`, `obsidian`, `neovim`
  - `papirus-icons`, `spicetify`

*(Note: These are kept here as ready-to-use references and are not currently active in `dotfiles/matugen/config.toml`)*
